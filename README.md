# Switchyard

Top-down, low-poly 6v6 team deathmatch built for iPhone.

**Play: https://dianteclark.github.io/Shooter/**

For fullscreen, open the link in Safari, tap Share, then Add to Home Screen. Hold the phone in landscape.

## Playing with friends
One person taps **Host a match** and shares the 4-character code. Everyone else taps **Join with a code**. Bots fill the empty slots on both teams at the difficulty the host picks.

## Controls
- Left stick: move. Push to the edge to sprint.
- Right stick: hold to aim down sights, push past the outer ring to fire. A quick flick hipfires.
- Buttons: slide, reload, swap to pistol, killstreak.

## Project
Plain HTML and ES modules with no build step; see `docs/ARCHITECTURE.md`.
