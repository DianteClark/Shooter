# Wave 6: make it play right (owner priority)

1. **Balance from data.** Every match records per-gun stats locally (kills, deaths with, shots, hits, headshots, time-to-kill on real kills, picks, damage by distance) for humans and bots. A Stats screen shows them and exports a compact code the owner can paste to the lead. Large bot simulations drive a balance pass now; real data drives later ones.
2. **Live tuning panel.** Hidden debug panel (long-press the timer, or `?tune=1`) to change feel mid-match: recoil and camera kick, aim assist strength and reach, stick sizes and fire ring, movement speed, sprint, slide, ADS speed. Values live in one registry `js/shared/tuning.js` (`TUNING`, `onTune`), persist locally, show which ones differ from default, reset per value or all, and export/import a code. Tuning is local to that phone: movement is client-authoritative, so it applies in solo and on guests; the host's own copy applies for bots only when the host changes it.
3. **Performance on real iPhones.** Optional FPS/frame-time overlay with a 1% low, GPU-bound vs CPU-bound hint and current quality step. Quality adapts to sustained frame time and to thermal pressure inferred from creeping frame times; an older-phone profile (detect by GPU renderer string / screen / memory hints) starts lower. Never stutter while switching.
